# investing-hub -- The Investing Hub

All investing research of the [Suggi-Workstation](https://github.com/Suggi-Workstation)
org lives here: portfolios, watchlist, company research, valuation
frameworks, and screening data.

**ASCII-only. Every file, every character. CI enforces it.**

## Structure

| Directory | What it holds |
|:--|:--|
| `portfolios/` | `main-portfolio.md`, `indo-portfolio.md`, `watchlist.md`. Suggi maintains the portfolios. |
| `companies/` | Company deep-dives and research files. |
| `frameworks/` | Valuation and scoring frameworks (DCF, financial scoring, moat scoring, screening guides). |
| `screening/` | Screening outputs. |
| `data/` | Screener exports and raw data files. |
| `documents/` | Source documents and filings. |
| `ideas/` | Investment ideas and theses. |

## House Rules

Every repo in this org follows the same rules: ASCII-only files,
lowercase-with-hyphens names, YAML frontmatter on every `.md`, no
secrets, no self-modification of governance files. See the
[terminal](https://github.com/Suggi-Workstation/terminal) repo for the
full rules and the governance core links.

New here? Start at the [terminal](https://github.com/Suggi-Workstation/terminal).
